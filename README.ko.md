# Gabbro: 이산 사건 시뮬레이션 기반 Raft 합의 엔진 & 카오스 주입기

[English](README.md) · [라이선스](LICENSE)

Gabbro는 물리적 벽시계 시간(Wall-clock time)과 OS 네트워크 소켓을 완전히 분리하고, 결정론적 이산 사건 시뮬레이터(Discrete-Event Simulator)로 구동되는 순수 Go 기반의 Raft 분산 합의 프로토콜 엔진입니다.

임의의 `time.Sleep` 대기 시간이나 실제 TCP 소켓을 사용하지 않고, 가상 우선순위 큐를 통해 상태 머신 노드 간의 메시지를 교환합니다. 네트워크 단절(Network Partition), 패킷 유실, 전송 지연이 64비트 PRNG 시드값으로 결정론적으로 제어되므로, 수만 번의 무작위 장애 상황을 시뮬레이션하고 버그 발생 시 동일한 시드만으로 실패 시퀀스를 100% 바이트 단위로 재현할 수 있습니다.

## 아키텍처 개요

```
                      +---------------------------------------+
                      |      중앙 이산 사건 우선순위 큐       |
                      |     가상 모노토닉 틱(Tick) 기준 정렬  |
                      +---------------------------------------+
                                    |           ^
                          이벤트 팝 |           | 응답 푸시
                                    v           |
+---------------------------------------------------------------------------------+
| 64비트 PRNG 시드 카오스 주입 엔진                                               |
|   - 패킷 유실 확률 (0.0 ~ 1.0)                                                  |
|   - 가상 틱 지연시간 지터(Jitter) 시뮬레이션                                    |
|   - 양방향 네트워크 분할 파티션 격리 ({0, 1} vs {2, 3, 4})                      |
+---------------------------------------------------------------------------------+
          |                               |                               |
          v                               v                               v
+-------------------+           +-------------------+           +-------------------+
| 노드 0: Follower  |           | 노드 1: Candidate |           | 노드 2: Leader    |
| - Term: 1         |           | - Term: 2         |           | - Term: 2         |
| - 로그 및 상태    |           | - 쿼럼 투표 수    |           | - NextIndex[]     |
| - 커밋 인덱스     |           | - 선거 타이머     |           | - MatchIndex[]    |
+-------------------+           +-------------------+           +-------------------+
```

## 왜 이산 사건 합의 검증인가?

분산 합의 시스템의 심각한 결함(스플릿 브레인, 커밋 누락, 파티션 복구 후 로그 불일치)은 밀리초 단위의 미세한 패킷 타이밍 경쟁 상태에서만 발생합니다. 실제 네트워크 소켓을 사용하는 기존 통합 테스트는 다음과 같은 한계가 있습니다:
1. **재현 불가능성(Flakiness)**: CI 환경의 네트워크 지연시간 차이로 인해 버그가 발생했던 정확한 패킷 순서를 다시 재현하기 어렵습니다.
2. **느린 실행 속도**: 실제 소켓 타임아웃과 하트비트를 기다리는 데 테스트당 수 초~수십 초가 소모됩니다.

Gabbro는 물리적 시간 대신 가상 이산 사건 틱을 사용합니다:
- **초고속 검증**: 5개 노드 클러스터의 500개 복제 트랜잭션 검증이 2밀리초 안에 완료됩니다.
- **100% 재현 보장**: 50,000번의 무작위 네트워크 장애 후 버그가 발견되더라도 동일한 시드 번호(`--seed`)만 입력하면 동일한 장애 시퀀스가 완벽히 재현됩니다.

## 듀얼 운영 프로시저

### 1. 카오스 스트레스 테스트 모드 (`--mode chaos`)
- 무작위 패킷 드롭 및 네트워크 지터를 주입하며 쿼럼 선거, 로그 복제, 리더 절체 불변식을 검증합니다.

### 2. 네트워크 분할 복구 모드 (`--mode partition`)
- 클러스터를 다수파와 소수파 파티션으로 분리한 후 소수파의 제안 거부, 다수파의 독립 합의를 확인하고, 파티션 치유(Heal) 후 로그 일치성을 검증합니다.

## 설치 및 빌드

```bash
git clone https://github.com/Aetherx86/Gabbro.git
cd Gabbro
go build -o bin/gabbro ./cmd/gabbro
```

## CLI 사용법

```bash
# 5개 노드 클러스터 대상 결정론적 카오스 시뮬레이션 실행 (시드 42)
./bin/gabbro -nodes 5 -ops 500 -drop 0.1 -seed 42 -mode chaos

# 네트워크 파티션 격리 및 복구 검증
./bin/gabbro -nodes 5 -ops 200 -mode partition -seed 1337
```
